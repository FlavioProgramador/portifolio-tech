# Portfólio | Flávio da Costa Marques

Este repositório reúne meu portfólio profissional como Desenvolvedor Full Stack.

## Sobre

O projeto apresenta minha trajetória, principais habilidades, certificações e projetos em destaque, com interface moderna, bilíngue (PT/EN) e foco em experiência visual.

## Destaques

- Apresentação profissional com identidade visual própria
- Sessões de trajetória, skills, certificações e recomendações
- Galeria de projetos com imagens e previews em vídeo
- Formulário de contato integrado

## Projetos em destaque

- Sim Aceito
- MeteoHUB
- TecnoBoard
- Jornada Viagens
- Gestão de Ativos Dress
- Controle de Notas
- Gerenciador de Tarefas
- Ignite Feed

## Tecnologias

- Next.js
- React
- TypeScript
- Framer Motion
